# مجلة جامعة جدارا الإلكترونية

الموقع العام + لوحة الإدارة + الباك إند في مشروع واحد (خادم Node.js يقدّم الواجهة وواجهة API معاً)، مع قاعدة بيانات PostgreSQL.
للتشغيل السريع من VS Code اقرأ **تشغيل_المشروع.md**.

## المتطلبات
- Node.js 22 أو أحدث، و PostgreSQL 14 أو أحدث.

## التشغيل المحلي
    npm install
    createdb jadara            # مرة واحدة
    npm run migrate            # ينشئ الجداول ويحمّل محتوى العرض
    npm run dev                # http://localhost:3000
الإعدادات في ملف `.env` (انسخه من `.env.example` أو شغّل `npm run setup`).

## النقل إلى سيرفر الجامعة
1. انسخ المشروع إلى السيرفر وثبّت Node.js 22+ و PostgreSQL، وأنشئ قاعدة ومستخدماً لها.
2. أنشئ `.env` من `.env.example` وعدّل:
   - `DATABASE_URL` ببيانات قاعدة الجامعة.
   - `NODE_ENV=production` و`COOKIE_SECURE=1` و`TRUST_PROXY=1`.
   - `SITE_URL` بالنطاق الرسمي.
   - `ADMIN_INITIAL_PASSWORD` بكلمة قوية جديدة، و`ADMIN_FORCE_CHANGE=1`.
   - `DATA_DIR` بمسار دائم للصور والملفات المرفوعة (ضمن النسخ الاحتياطي).
3. `npm ci --omit=dev && npm run migrate && npm start` (للتشغيل الدائم استخدم مدير عمليات الجامعة مثل systemd أو pm2).
4. وجّه خادم الويب الخاص بالجامعة (HTTPS + النطاق) إلى `http://127.0.0.1:3000`.
5. فحص الحالة: `GET /healthz`.
- بدلاً من ذلك يمكن استخدام `docker compose up -d --build` (ملفا `Dockerfile` و`docker-compose.yml` جاهزان، ويلزم `POSTGRES_PASSWORD` في `.env`).

## متغيرات البيئة
| المتغير | الوظيفة |
|---|---|
| DATABASE_URL | عنوان PostgreSQL (إلزامي) |
| DATABASE_SSL | 1 إن كانت القاعدة تتطلب SSL |
| NODE_ENV / PORT | وضع التشغيل والمنفذ |
| COOKIE_SECURE / TRUST_PROXY | 1 و1 خلف HTTPS |
| SITE_URL | النطاق الرسمي (روابط المشاركة والفهرسة) |
| ADMIN_INITIAL_PASSWORD | كلمة مرور المدير عند أول تشغيل (تُخزَّن مشفّرة) |
| ADMIN_FORCE_CHANGE | 0 يلغي إجبار تغيير كلمة المرور (للعرض المحلي فقط) |
| DATA_DIR | مجلد الصور والملفات المرفوعة |
| CLOUDINARY_URL | اختياري: تخزين خارجي بدل المجلد المحلي |
| SEED_DEMO | 1 محتوى عرض عند أول تشغيل، 0 إطلاق نظيف |
| BACKUP_DIR / BACKUP_KEEP | النسخ الاحتياطي |
| POSTGRES_PASSWORD / APP_PORT | docker compose فقط |

## الصيانة
| المهمة | الأمر |
|---|---|
| نسخة احتياطية | `npm run backup` (القاعدة) + نسخ مجلد `DATA_DIR/uploads` (الملفات) |
| استعادة | `npm run restore -- backups/<تاريخ>/db.json --yes` |
| نسيان كلمة مرور المدير | `npm run reset-admin -- "كلمة_مؤقتة_جديدة"` |
| حذف محتوى العرض | لوحة الإدارة ▸ الإعدادات ▸ حذف المحتوى التجريبي |

## الأمان
bcrypt · جلسات بكوكي HttpOnly + SameSite=Strict (+Secure) · حد محاولات الدخول · حماية CSRF · تحقق من المدخلات في الخادم · استعلامات مهيّأة · رفع ملفات بقائمة أنواع وفحص توقيع وحد 60MB · Helmet/CSP · سجل نشاطات. لا أسرار في الكود.

## الفهرسة والمشاركة
`/a/<رقم>` للمواد، `/s/<1-12>` للأبواب، `/p/<اسم>` للصفحات، مع Open Graph وSchema.org و`/sitemap.xml` و`/robots.txt`.
